# MSOLID TECH SOLUTIONS - Professional Technology Website

A complete, responsive, and modern technology company website built with HTML5, CSS3, Vanilla JavaScript, and Flask (Jinja2).

## Features
- Fully Responsive Design
- Dark/Light Mode Toggle
- Smooth Scroll & Entrance Animations
- Glassmorphic UI Elements
- Flask/Jinja2 Template Integration
- Dynamic Portfolio Filtering
- Animated Counters & Progress Bars

## Project Structure
- `app.py`: Flask application routing.
- `templates/`: Jinja2 HTML templates.
- `static/`: CSS, JS, and image assets.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python app.py`
